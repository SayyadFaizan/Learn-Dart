# Learn Dart 🎯

> A structured code repository for mastering Dart programming—the essential prerequisite for building cross-platform applications with Flutter.

## 🚀 About the Project

This repository serves as a hands-on learning environment for **Dart**, the modern, object-oriented programming language developed by Google. Because Dart is the foundational language of the Flutter framework, grasping its core concepts is a crucial first step before diving into mobile, web, or desktop app development.

Inside, you'll find practice files, foundational code snippets, and project structures designed to make the transition into Flutter seamless.

## 📁 Repository Structure

* **`Dart Basic/`** — Contains introductory code, core syntax examples, and foundational Dart concepts.
* **`test.dart`** — A scratchpad file for testing functions, algorithms, and quick Dart snippets.
* **`.idea/` & `Learn Dart.iml`** — Project configuration files for seamless integration with IntelliJ IDEA or Android Studio.

## 🛠️ Tech Stack

* **Language:** Dart (100%)
* **Target Framework:** Flutter (Preparation)
* **IDE Readiness:** Android Studio / IntelliJ IDEA

## 📖 Why Learn Dart?

To build beautiful, natively compiled applications from a single codebase using Flutter, you need a strong command of Dart. This repository is built to help you practice the fundamentals, including:
* Variables, Data Types, and Null Safety
* Control Flow Statements (If/Else, Loops)
* Object-Oriented Programming (Classes, Mixins, Inheritance)
* Asynchronous Programming (Futures, Streams, `async`/`await`)

## 💻 Getting Started

### Prerequisites
To execute the code in this repository, you need the Dart SDK installed on your machine.
1. Download the SDK from the [official Dart website](https://dart.dev/get-dart).
2. *Note: If you already have the Flutter SDK installed, Dart is included automatically!*

### Running the Code
1. Clone the repository to your local machine:
   ```bash
   git clone [https://github.com/SayyadFaizan/Learn-Dart.git](https://github.com/SayyadFaizan/Learn-Dart.git)

2. Navigate into the project directory:
   ```bash
   cd Learn-Dart
   ```
3. Run any Dart file directly from your terminal. For example:
   ```bash
   dart run test.dart
   ```
